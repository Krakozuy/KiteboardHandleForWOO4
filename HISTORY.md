# История KiteHandleWoo

Git создан 7 сентября 2026 года. Версии 1.0.11–1.0.17 импортированы из сохранённых папок work/package-<версия>/KiteHandleWoo как последовательные коммиты одного и того же пути outputs/KiteHandleWoo.

Это восстановленные снимки выпусков, а не первоначальные коммиты разработки. Даты коммитов соответствуют импорту; промежуточные правки между снимками неизвестны. Более ранних исходников в проекте не найдено.

| Тег | Содержание сохранённой версии |
| --- | --- |
| v1.0.11 | Защёлка в плоскости крышки, сквозной П-паз, скос левого язычка |
| v1.0.12 | Скруглённый контур зазора у поворотного края |
| v1.0.13 | Тонкий конец жёсткого зацепа и карман с учётом заведения |
| v1.0.14 | Посадочные зазоры 0,1 мм на сторону |
| v1.0.15 | Полукруглые окончания П-паза без ступенек |
| v1.0.16 | Оффсет профиля полости WOO наружу на 3 мм |
| v1.0.17 | Русские комментарии к настройкам, функциям и этапам построения |

Последующие законченные изменения сохраняются отдельными коммитами согласно AGENTS.md. Локальный автор автоматических коммитов — Codex <codex@localhost>; это не учётная запись пользователя на сервисе Git.

Посмотреть историю скрипта:

```sh
git log --oneline --follow -- outputs/KiteHandleWoo/KiteHandleWoo.py
```

Посмотреть изменения между версиями:

```sh
git diff v1.0.16 v1.0.17 -- outputs/KiteHandleWoo/KiteHandleWoo.py
```

Получить текст скрипта старой версии без изменения рабочей копии:

```sh
git show v1.0.11:outputs/KiteHandleWoo/KiteHandleWoo.py
```

Репозиторий локальный. Сам Git не записывает каждое сохранение файла автоматически: история пополняется коммитами. Изменения, сделанные вручную вне работы агента, также нужно коммитить.
